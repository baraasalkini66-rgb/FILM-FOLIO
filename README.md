# Film Folio

## Project Overview

Film Folio is a small prototype created from the Directors Notes Film Folio brief.

The aim is to present important information about a film in a simple and clear way.

## Intended Visitor

Someone reading about a film who wants to quickly find key information such as the film description, runtime, country and credits.

## Starting Point

The prototype currently contains one fictional film:

**The Quiet Cartographer**

It includes:

- Film title
- Short description
- Runtime
- Country
- Credits

## Technologies Used

- HTML
- CSS
- JavaScript

## Week 3 Interaction

The visitor can click the **Show credits** button to reveal the film credits.

When the credits are visible, the button changes to **Hide credits**.

Clicking it again hides the credits.

## Future Improvements

Possible future improvements could include:
